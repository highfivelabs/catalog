# Terraform coverage data

Generated by `hack/terraform/` (see `docs/terraform-leverage.md` for the method,
the pins and the error of these numbers). Nothing here is hand-edited except
`hack/terraform/overrides.csv`.

| Path | Use |
| --- | --- |
| `config-connector-extensions/`, `ack-extensions/`, `aso-extensions/` | one pair of files for each repository's `docs/coverage/`: `terraform.csv` (one row per service and provider, keyed like `services.csv`) and `terraform-resources.csv` (one row per resource and provider, keyed like `resources.csv`). They do not change the shared CSV schemas. |
| `summary.csv` | the headline table: each provider against the whole API and each category |
| `data/` | inputs and intermediate files: flattened provider schemas, the resource mapping, Magic Modules' definitions, the foundation-gap table |
| `spikes/` | logs and artifacts of the two spikes |

Columns of `terraform.csv`:

- `provider`: `google`, `google-beta` (config-connector-extensions), `aws`
  (ack-extensions) or `azurerm` (aso-extensions). `azapi` is not a row: it takes
  any ARM resource type with a free-form body, so it covers every resource by
  construction and no attribute as a typed schema.
- `attributes_terraform_l1`, `attributes_terraform_l2`: attributes of the
  denominator that a writable attribute of a mapped Terraform resource
  matches, by the strict (L1) and the lenient (L2) rule; L1 is the floor.
  `pct_*` are shares of `attributes_total`.
- `attributes_official_and_terraform`, `attributes_ours_and_terraform`: the
  overlap (L2) with the official controller's attributes and with the ones
  only our kinds have.
- `attributes_terraform_only`: Terraform (L2) and neither official nor ours.
- `attributes_official_or_ours_without_terraform`: official or ours and not
  Terraform (L2).
- `pct_official_ours_terraform_union`: official, ours and Terraform together.
- `pct_terraform_within_mapped_resources`: L2 over only the attributes of
  resources that have a mapped Terraform resource (the "how complete is it
  where it exists" figure).
